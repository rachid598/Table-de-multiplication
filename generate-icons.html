Générateur d'icônes PWA

Cet outil génère les icônes nécessaires pour l'application PWA.

Instructions :

  1. Cliquez sur "Générer les icônes" pour créer toutes les tailles
  2. Cliquez sur "Télécharger toutes les icônes" pour les sauvegarder
  3. Placez les fichiers téléchargés dans le dossier icons/
